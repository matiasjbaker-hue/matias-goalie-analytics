Analytics Platform

This platform tracks traditional goaltending statistics alongside shot-level and situational performance.

Advanced metrics include expected save percentage, expected goals against, goals saved above expected and shot-quality analysis.

Rebound Control is tracked separately using manually collected directional rebound-control data.
